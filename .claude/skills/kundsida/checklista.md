# Checklista före bygget

Jämför alltid med paketbeskrivningen i `public/index.html`, som är facit.

## Alla paket

- [ ] Företagsnamn, exakt som det ska skrivas (stora och små bokstäver).
- [ ] Logga, helst SVG eller PNG med genomskinlig bakgrund.
- [ ] Bilder: produkter, lokal eller personerna bakom. Hellre några bra än många dåliga.
- [ ] Vad företaget gör, med kundens egna ord.
- [ ] Vad besökaren ska göra på sidan (beställa, ringa, boka, mejla).
- [ ] Kontaktuppgifter som ska synas: e-post, telefon, adress.
- [ ] Sociala länkar som fullständiga adresser, inte bara "TikTok".
- [ ] Kontaktperson hos kunden: vem vi pratar med.
- [ ] Samtycke till att Nordvy får visa sidan som exempel (finns i intervjun som "referens").

## UF-paket

- [ ] Produkterna (upp till 10): namn, pris, kort beskrivning och en bild per produkt.
- [ ] E-postadressen dit beställningar ska gå.
- [ ] Hur kunden får varan: hämtning, utskick eller båda.
- [ ] En kort text om UF-företaget och vilka som driver det.

## Bas och Premium

- [ ] Tjänster eller meny, med priser om de ska synas.
- [ ] Öppettider, eller att de bara finns online.
- [ ] Adress för kartan.
- [ ] Domänönskan. Domänen registreras i kundens namn.
- [ ] Premium, bokning: vad som ska kunna bokas (tjänst, tid, pris) och kundens Cal.com-länk. Kunden skapar ett gratiskonto på cal.com i sitt eget namn. Vi hjälper till men får aldrig lösenordet.
- [ ] Premium, betalning: kundens nummer för Swish Företag (inte ett privat nummer), och vad besökaren ska skriva som meddelande.
- [ ] Premium, omdömen: om kunden vill ta emot omdömen, och riktiga omdömen som får visas från start.

## Fotoguide till kunden

Fotona avgör mer än något annat hur sidan ser ut. Skicka med det här i mejlet när bilder saknas, anpassat efter kunden:

> **Så tar ni bilderna med mobilen**
> - Fota i dagsljus, nära ett fönster. Stäng av blixten.
> - Ta bilder på riktiga saker i riktig miljö: händerna i arbete, lokalen, produkterna där de brukar stå.
> - Undvik skyltar, prislappar och text i bilden.
> - Ta varje motiv både liggande och stående.
> - Skicka bilderna i originalstorlek, gärna via Google Drive eller WeTransfer, så att de inte blir suddiga.
>
> Det här behöver vi: [lista per kund, till exempel "3–4 bilder på bröden i disken", "en bild på er som bakar", "en bild på lokalen utifrån"].

Har kunden inga bra bilder kan Nordvy erbjuda att komma och fota. Det är ett beslut för Måns, så föreslå det bara i mejlet om Måns har sagt ja.

## Mall för mejlet om det som saknas

Skapa det som ett utkast i Nordvys Gmail. Skicka det aldrig själv.

> **Ämne:** Er hemsida med Nordvy – det här behöver vi från [företag]
>
> Hej [förnamn]!
>
> Tack för att ni valt [paket]! Vi har börjat på er sida och behöver några saker till för att göra den klar:
>
> 1. [Det som saknas, en sak per rad, med ett exempel på vad vi menar]
> 2. …
>
> Svara gärna direkt på det här mejlet och bifoga bilderna. Vi bygger klart sidan inom 7 dagar från att vi har fått allt.
>
> Hälsningar,
> Nordvy UF

Håll mejlet kort. Fråga bara om det som verkligen saknas, och skriv det som konkreta frågor, till exempel "Vad kostar boken?" i stället för "Pris".
